Reward computed in SnakeGame._calculate_reward (snake_game.py).

Mutually exclusive cases, evaluated in order:

  1. Game over (wall or self collision)         => -10.0
  2. Food eaten on this step                    => +10.0
  3. Manhattan distance to food decreased       =>  +0.3
  4. Manhattan distance to food increased       =>  -0.3
  5. Otherwise (distance unchanged)             =>   0.0

Notes:
- No survival bonus per step.
- No spatial / open-space penalty in the reward (spatial info is in the
  state vector instead, so the agent learns to use it via Q-values).
