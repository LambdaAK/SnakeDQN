How it works

A fast simulator

Standard Battlesnake rules (simultaneous moves, health, head-to-head collisions) implemented in vectorised NumPy, stepping 1,024 games at once at over 200,000 turns per second. Every rule is checked against an independent reference implementation.

Self-play training

A small convolutional actor-critic sees the board as 8 feature planes from its own point of view. It is trained with PPO against its current self and a pool of frozen past selves. Reward is just +1 for winning and −1 for losing, plus a tiny bonus for eating.

Running in your browser

The trained network is exported to ONNX and runs with ONNX Runtime Web. The game rules were ported to JavaScript and verified move-for-move against the Python simulator, so what you see is exactly the game it trained on.

Training progress
